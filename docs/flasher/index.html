Flash direct depuis le navigateur — Chrome / Edge desktop, ou Chrome Android + câble OTG.

📷 Caméra ESP32-CAM

AI-Thinker / Binghe + OV3660

Navigateur non supporté — utilise Chrome ou Edge. HTTPS requis.
  1. Branche la carte sur son adaptateur ESP32-CAM-MB (ou un FTDI).
  2. Maintiens BOOT (ou relie GPIO 0 à GND) pendant le branchement.
  3. Lance le flash, puis relâche et appuie sur RESET.

📺 Moniteur ESP32-S3

Guition 4827S043 — 4,3″ 480×272 tactile

Navigateur non supporté — utilise Chrome ou Edge. HTTPS requis.
  1. USB-C natif : branche simplement la carte.
  2. Si elle n'apparaît pas, maintiens BOOT puis appuie brièvement sur RESET.
Ta configuration est préservée. Le flasher n'écrit que le bootloader, la table de partitions, l'otadata et l'application. La partition NVS (0x9000), qui contient le WiFi, le token Telegram et le nom de la caméra, n'est pas touchée — inutile de repasser par le portail après un flash.

Si tu choisis Erase device dans la boîte de dialogue, en revanche, tout est effacé et la carte redémarre sur son point d'accès ESP32-CAM-Setup-xxxx.
